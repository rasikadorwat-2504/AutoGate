# Automated Food Dispenser

A smart automated food dispensing system that stores food and dispenses a controlled portion at scheduled times using a motor and controller.

## Components Used
- DC / Servo motor
- Motor driver
- Arduino / ESP32
- Food storage hopper
- RTC module
- Power supply
- Buzzer / LED
- Sensors

## How It Works

The system stores food in a hopper. At the scheduled feeding time, the controller activates the motor, which operates the dispensing mechanism to release a predefined quantity of food. Sensors help monitor the food level and dispensing process. The system can also be operated manually and alerts the user when required.
