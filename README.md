# AutoGate

Smart automatic gate system that opens and closes using sensors and a motor, with secure access control.

## Features
- Sensor द्वारे automatic gate open/close
- Motor control
- Secure access control (RFID / password)
- Safety: obstacle detection

## Components Used
- Microcontroller (Arduino / ESP32)
- Ultrasonic / IR sensor
- DC / Servo motor
- Motor driver
- Power supply

## How It Works
1. The sensor detects a vehicle or person.
2. Access is verified.
3. The motor opens the gate and closes it after a short time.
